## Как вести этот документ

1. **Перед работой**: выбрать ближайшую открытую задачу в [BACKLOG-IMPROVEMENTS.md](BACKLOG-IMPROVEMENTS.md), уточнить результат и критерий проверки по соответствующему UC.
2. **После подтверждённого результата**: обновить Current State и добавить датированную запись в History с коммитом/ссылкой и уровнем проверки; закрыть соответствующий пункт backlog. Не считать реализованное и проверенное одним статусом.
3. **Если меняется направление**: менять приоритеты и незавершённые работы только в backlog; прежние решения сохранять здесь в History, не переписывая проверенные факты.
4. Не повторять здесь API, архитектуру, команды PowerShell, будущие задачи и процедуры UC: давать ссылки на их нормативных владельцев.
5. Action System — центральная целевая подсистема, Feedbrain — самостоятельный необязательный сервис; внешние API/MCP/приложения — альтернативные инструменты.

Отметки готовности в Current State и History — **только по наблюдавшейся проверке**; незавершённость описывать лишь как проверенное ограничение и ссылкой на backlog.

## Current State — что есть прямо сейчас

**Коротко:** Feedbrain уже можно запустить и использовать как RSS-архив с поиском. **Ручной Action V1 end-to-end проверен на Windows Docker/PostgreSQL через Fortis Repo:** Action #1 v3 → ActionRun #1 → отдельный Action worker → Feedbrain IngestionRun #6 → StepRun и ActionResult со статусом completed. **Action Scheduler проверен на Windows Docker/PostgreSQL:** явно включено расписание Action #1 v3, автоматически созданы ActionRun #2 и #3 с `initiated_by: schedule`, оба завершились успешно через Feedbrain IngestionRun #7 и #8; расписание после проверки **выключено**. Шесть конкурентных ручных запусков проверены (один `202`, пять `409`); **Scheduler vs. manual также проверен:** ручной Run #8 занял Action, Scheduler записал `active_run` без дубля. Внешний HTTP 404 сохранён как failed. Исправление Action без `schedule` подтверждено на Docker (диагностический Run #7). **Перезапуск worker с включённым расписанием и последующий автоматический запуск полностью подтверждены:** ActionRun #9 → StepRun #9 → Feedbrain IngestionRun #17, все `completed`. Скрипт отключил расписание. Аварийное восстановление выполняющегося Run и внешний timeout ещё не проверены. Внешний AI может читать, менять версии и запускать Actions через HTTP.

FTS ищет по fragments, поэтому несколько hits одной статьи — ожидаемое поведение; семантического поиска нет. Фоновая массовая веб-экстракция, расширенный импорт PDF/CSV/JSON, generic API connectors и встроенная LLM не реализованы.

**Открытые задачи и текущий приоритет:** [BACKLOG-IMPROVEMENTS.md](BACKLOG-IMPROVEMENTS.md). В частности, внешний timeout, авария во время running Run и disposable-DB SQL/API тесты ещё не подтверждены. **Перезапуск worker и новый scheduled Run подтверждены** — см. историю ниже.
