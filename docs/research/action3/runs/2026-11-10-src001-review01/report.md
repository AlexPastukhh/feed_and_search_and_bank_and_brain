## OVERVIEW

**SRC-001 нельзя сейчас считать готовым источником постоянного мониторинга.**
Официальный SDK поддерживает поиск через OAuth2 (EV-001), но
API Terms (EV-002) ограничивают хранение Data и кэширование; общий
User Agreement регулирует автоматизированный доступ (EV-003).
Право на нужную нам долгосрочную историю проектов не установлено.

Публичная карточка свидетельствует о наличии клиентской задачи на
CRM/API-интеграции (EV-004), но один пример не доказывает размер рынка
или доходность. Не создаём скрейпер и базу объявлений.

**Самый дешёвый следующий эксперимент** — проверить один разрешённый
Saved Search Upwork (EV-005). RSS Upwork отключён (EV-006). Реальный
доступ к пользовательскому аккаунту и поиск ещё не проверены.
