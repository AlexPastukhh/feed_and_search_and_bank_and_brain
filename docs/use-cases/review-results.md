# UC-ACT-009 — Обсудить результат и применить выбранные предложения

**Когда:** после исследования или другого Action сохранены находки,
новые Sources, идеи новых Actions или изменения уже существующих.

**Цель:** перейти от результата AI к **осмысленному решению и проверенному
действию**, не смешивая «предложено», «одобрено» и «выполнено».

**Предпосылки:** доступен адресуемый результат с версией исходного Action,
датой, ссылками на первоисточники и ID предложений. Способ чтения реально
разрешён, а не предполагается по наличию файла/сервиса.

**Как:**
1. Получить сохранённый отчёт через существующий Tool/проект, прочитать
   ID `report_id`, номер версии, охват, Evidence и ограничения.
   PR без merge не считать уже принятым архивом в `main`.
2. Обсудить один или несколько элементов по стабильным ссылкам,
   например `report_id#SRC-001`, `#RES-001` и `#MON-001`.
   Проверить доказательства, смысл Source, пересечения с имеющимися
   Actions/Tools и применимость к текущим целям.
3. Для выбранного элемента определить действие: проверить доступ
   к источнику, создать/изменить исследовательский Action, создать/
   изменить мониторинговый Action, настроить Tool или отклонить идею.
   Перед записью сверить действительный контракт интеграции,
   права, актуальную версию целевого Action и необходимость одобрения.
4. После решения пользователя выполнить только разрешённую операцию
   через настоящий API/Registry/Gateway. Предложение исследования
   **не** становится автоматическим разрешением на запись или запуск.
5. Прочитать результат операции обратно и отдельно зафиксировать
   решение, фактический Action ID/версию, ID настроенного источника
   или мотивированный отказ **со ссылкой на исходное предложение**.
   Исторический отчёт не переписывать.

**Готово:** понятно, какое предложение принято или отклонено,
что реально изменилось и как проверено; связь с доказательствами
и исходным исследованием доступна для повторного чтения.

**STOP / UNKNOWN:** отчёт не найден, источник непроверен, право записи
не подтверждено, версия target Action изменилась, внешний эффект
неоднозначен. Не обходить ограничения инструмента и Gateway.

**Статус:** повторяемый целевой маршрут. У Action #3 есть пример
предметного контракта и архива [здесь](../research/README.md);
автоматического механизма принятия предложений нет.
